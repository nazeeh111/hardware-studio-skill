Feature dimensions


Edit a feature to set its size and position. New features use example dimensions until you replace them. Apply changes to retain the source, then generate to check the shape.




Editable source / JSON
Dimensions and JSON edit the same working source. Box origin is its minimum corner; cylinder and polygon origin is the base position. Positive extrusion axes: +Z uses local X/Y points, +X uses Y/Z, +Y uses Z/X. The polygon closes automatically. All dimensions are millimeters. Region checks only test their supplied regions.


Supported fields and limits
1–32 ordered add/cut features, with box size [X,Y,Z], cylinder radius/height/axis, or a 3–64-corner simple polygon with height and axis. Polygon points must not cross, touch, repeat or contain a straight-through corner. Coordinates stay within ±500 mm; positive lengths range from 0.01 to 500 mm; final spans cannot exceed 500 mm. IDs must be unique. The resulting volume and each operation’s volume change must exceed 0.001 cubic millimeters; disconnected bodies are rejected. Up to 16 material/void probes are checked after building and after STEP readback.
This modeler supports axis-aligned feature solids. Curved or multiply connected profiles, freehand sketch interpretation, fillets, threads and lofts are not supported. Place separate part sources in the assembly workspace. The feature JSON retains the operation sequence; STEP carries the resulting surfaces.
