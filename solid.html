Feature dimensions


Edit a feature to set its size and position. New features use example dimensions until you replace them. Apply changes to retain the source, then generate to check the shape.




Editable source / JSON
Dimensions and JSON edit the same working source. Box origin is its minimum corner; cylinder and extruded-profile origin is the base position. Positive extrusion axes: +Z uses local X/Y points, +X uses Y/Z, +Y uses Z/X. Polygons close automatically; line/arc profiles close explicitly at Start. Fillets use points inside existing edges, away from vertices. All dimensions are millimeters. Region checks only test their supplied regions.


Supported fields and limits
1–32 ordered features: add/cut boxes and cylinders, polygon or line/arc extrusions, and edge-seed fillets. Polygons use 3–64 corners; curved profiles use 2–64 line/three-point-arc segments, one closed loop and a positive height/axis. A circle uses two arcs. Fillets use radius and 1–16 seed points that each resolve exactly one current edge. Polygon points must not cross, touch, repeat or contain a straight-through corner. Coordinates stay within ±500 mm; positive lengths range from 0.01 to 500 mm; final spans cannot exceed 500 mm. IDs must be unique. The resulting volume and each operation’s material change must exceed 0.001 cubic millimeters; disconnected bodies are rejected. Up to 16 material/void probes are checked after building and after STEP readback.
This modeler supports axis-aligned feature solids. Circular arcs and constant-radius fillets need the optional project CAD runtime. Fillets can extend through tangent edges; inspect the generated contour. Splines, multiply connected profiles, freehand sketch interpretation, threads and lofts are not supported. Cut holes as separate features. Place separate part sources in the assembly workspace. The feature JSON retains the operation sequence; STEP carries the resulting surfaces.
