This package retains a captured mesh image, geometry identity and user-owned qualitative feature list. observation.json records either advisory model observations or NOT RUN. raw-model-response.json, when present, is untrusted model text and may contain false statements. It does not alter CAD or project review marks. Geometry hashes identify parsed Float32 render data; the image SHA-256 identifies the exact PNG supplied to Ollama. No physical or dimensional verification is claimed.
