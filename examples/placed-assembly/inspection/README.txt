Three orthographic views of the visible rendered STL triangles.
The accompanying manifest identifies geometry with SHA-256 of Float32 little-endian interleaved x,y,z,nx,ny,nz vertex data after STL parsing. It is not the hash of the original STL file. All views use one pixel scale and original shared positions; hidden meshes and display-only lift are excluded.
STL units are assumed millimeters. This is a surface inspection sheet, not a dimensioned drawing, solid validity check, collision check or physical engineering test. This export does not run AI.
